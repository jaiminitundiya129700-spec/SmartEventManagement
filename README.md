# Smart Event Management System
**Course:** .NET Technologies (01CE1523) – Mini Project

## Problem Statement
Colleges and clubs manage events with paper forms and WhatsApp groups, which causes overbooking, lost registrations and no clear records.

## Objectives
- Create, edit, delete and search events
- Online attendee registration with automatic seat tracking
- Dashboard with live statistics (events, tickets, revenue)

## Technology Stack
C#, ASP.NET Core MVC (.NET 8), Entity Framework Core, SQLite, Bootstrap 5, Git/GitHub

## Run
1. Install .NET 8 SDK
2. `dotnet restore`
3. `dotnet run`
4. Open the URL printed in the terminal (e.g. http://localhost:5000)
